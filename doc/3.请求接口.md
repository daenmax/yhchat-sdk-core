## 请求接口

工具类为：MessageUtil、GroupUtil、BoardUtil等

静态调用即可

| 方法           | 对应           |
|--------------|--------------|
| 发送消息         | sendMsg      |
| 批量发送消息       | sendMsgBatch |
| 更多不再一一列举.... | ....         |

## 示例

```java
//发送消息
ApiSendMsgReqV1 reqV1 = new ApiSendMsgReqV1()
        .Text(RecvTypeConstant.USER, "4137637", "你好")
        .addButton("跳转", ButtonActionTypeConstant.JUMP_URL, "https://www.baidu.com/", null)
        .addButton("复制", ButtonActionTypeConstant.COPY, null, "复制成功啦")
        .addButton("上报", ButtonActionTypeConstant.REPORT, null, "上报成功啦");
ApiSendMsgRetV1 apiSendRetV1 = MessageUtil.sendMsg(reqV1);

//批量发送消息
ApiSendMsgBatchReqV1 reqBatchV1 = new ApiSendMsgBatchReqV1()
        .Text(RecvTypeConstant.GROUP, Arrays.asList("956034802", "123456789"), "你好2")
        .addButton("跳转", ButtonActionTypeConstant.JUMP_URL, "https://www.baidu.com/", null)
        .addButton("复制", ButtonActionTypeConstant.COPY, null, "复制成功啦")
        .addButton("上报", ButtonActionTypeConstant.REPORT, null, "上报成功啦");
ApiSendMsgBatchRetV1 apiSendMsgBatchRetV1 = MessageUtil.sendMsgBatch(reqBatchV1);
```

## 群组管理

工具类为：GroupUtil

静态调用即可

| 方法 | 对应 |
| --- | --- |
| 创建标签 | createTag |
| 修改标签 | editTag |
| 删除标签 | deleteTag |
| 获取群标签列表 | tagList |
| 给用户添加标签 | addUserTag |
| 给用户移除标签 | removeUserTag |
| 移除群成员 | removeMember |
| 群成员禁言 | gagMember |
| 群内消息类型控制 | msgTypeLimit |

## 群组管理示例

```java
//创建标签
ApiGroupTagCreateRetV1 createRet = GroupUtil.createTag(new ApiGroupTagCreateReqV1("123456", "VIP用户", "#FF5733", "VIP会员用户标签", 1L));

//修改标签
ApiGroupTagEditRetV1 editRet = GroupUtil.editTag(new ApiGroupTagEditReqV1("123456", "VIP用户", "SVIP用户", "#FF5733", "VIP会员用户标签（已更新）", 2L));

//删除标签
ApiGroupTagDeleteRetV1 deleteRet = GroupUtil.deleteTag(new ApiGroupTagDeleteReqV1("VIP用户", "123456"));

//获取群标签列表
ApiGroupTagListRetV1 tagListRet = GroupUtil.tagList(new ApiGroupTagListReqV1("123456"));

//给用户添加标签
ApiGroupTagUserRelateRetV1 addUserTagRet = GroupUtil.addUserTag(new ApiGroupTagUserRelateReqV1("7058262", "VIP用户", "123456"));

//给用户移除标签
ApiGroupTagUserRelateCancelRetV1 removeUserTagRet = GroupUtil.removeUserTag(new ApiGroupTagUserRelateCancelReqV1("7058262", "VIP用户", "123456"));

//移除群成员
ApiGroupRemoveMemberRetV1 removeMemberRet = GroupUtil.removeMember(new ApiGroupRemoveMemberReqV1("7058262", "123456"));

//群成员禁言（600秒）
ApiGroupGagMemberRetV1 gagMemberRet = GroupUtil.gagMember(new ApiGroupGagMemberReqV1("7058262", "123456", 600L));

//群内消息类型控制（只允许文本和图片消息）
ApiGroupMsgTypeLimitRetV1 msgTypeLimitRet = GroupUtil.msgTypeLimit(new ApiGroupMsgTypeLimitReqV1("123456", "text,image"));
```
